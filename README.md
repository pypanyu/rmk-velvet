# RMK Firmware for handwired/hafu/crkbd

RMK Firmware for `handwired/hafu/crkbd` created to experiment with RMK
keyboard firmware.

- [handwired/hafu/crkbd in qmk_firmware](https://github.com/hafu/qmk_firmware/tree/hafu_crkbd/keyboards/handwired/hafu/crkbd)
- [handwired/hafu/crkbd qmk_userspace](https://github.com/hafu/qmk_userspace/tree/hafu_crkbd/keyboards/handwired/hafu/crkbd/pi_pico/keymaps/miryoku)
- [RMK docs](https://rmk.rs/docs/getting_started/introduction.html)

## Build

```shell
cargo make uf2 --release
```
